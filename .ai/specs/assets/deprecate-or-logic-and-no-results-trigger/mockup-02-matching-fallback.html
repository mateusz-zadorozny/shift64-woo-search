Matching & Fallback

Two search settings are deprecated. They still work, and will be removed in a future release.

  • Search Logic is set to OR. Measured worse than AND on precision and latency, with no case where it wins. → Basic Ranking
  • Fallback Trigger is set to Only when no results. It disables the fallback ladder, so a typo in one word of a multi-word query is never repaired. → Matching & Fallback
