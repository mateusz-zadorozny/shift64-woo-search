Shift64 Woo Search connects WooCommerce product search, autocomplete, and facets to Redis and RediSearch while WooCommerce continues to render products and apply business logic.

Use this site for maintained plugin documentation. New documentation pages belong in `docs/src/content/docs/` and should be committed with the related code change.

Start with [Requirements](/getting-started/requirements/) to prepare WordPress, WooCommerce, PHP, and Redis.
